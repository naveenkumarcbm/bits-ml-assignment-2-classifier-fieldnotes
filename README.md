# Classifier Fieldnotes

An educational comparison of five classification algorithms on the UCI Wisconsin Diagnostic Breast Cancer (WDBC) dataset. The app evaluates uploaded, labeled rows against saved models; it never retrains on uploaded data.

## a. Problem statement

Compare Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Support Vector Machine classifiers for a binary diagnosis label. Report Accuracy, AUC, Precision, Recall, F1, and Matthews Correlation Coefficient (MCC) on the same stratified held-out test split. This is a classroom exercise, not a medical diagnostic tool.

## b. Dataset description

- **Source:** UCI Machine Learning Repository, [Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic); accessed through `sklearn.datasets.load_breast_cancer`.
- **Size:** 569 instances and 30 numeric input features, exceeding the assignment minimums.
- **Target:** `diagnosis`, with values `malignant` and `benign`.
- **Split:** 75% training and 25% held-out test data, stratified by target, with random seed 42.
- **Test file:** `test_data.csv` is generated by `train_models.py` from that fixed split. It includes the target column for metric calculation.
- **Positive class:** `malignant` for AUC, Precision, Recall, and F1.

## Application

The Streamlit app provides a CSV upload, compares all five saved classifiers, and displays metrics, a confusion matrix, and a classification report for the selected model. Input CSVs must contain all 30 feature columns and `diagnosis`.

### Run locally

```bash
python -m pip install -r requirements.txt
python train_models.py
streamlit run app.py
```

`train_models.py` must be run once to create the five `model/*.joblib` artifacts and the labeled `test_data.csv`. The Streamlit app only loads these artifacts and scores the uploaded data.
